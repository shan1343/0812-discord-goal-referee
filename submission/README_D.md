# D 제출 폴더 안내

D 책임 범위의 기준 문서는 다음과 같다.

- 사용자 테스트 계획: `research/user_test_plan.md`
- 사용자 테스트 실제 결과: `research/user_test_results.md`
- 45초 데모: `demo/demo_script.txt`
- 5분 발표 및 3회 리허설: `presentation/run_of_show.md`
- 필수 통과/평가 증거: `evidence/pass_matrix.md`
- 캡처 규칙: `evidence/capture_checklist.md`
- 팀 전달 차단사항: `handoff/d_priority_report.md`
- 데모 prompt: `prompts/demo_prompt.md`
- 검증된 외부 링크: `evidence/links.md`

`PENDING`, `NOT RUN`, `NOT VERIFIED`는 실제 증거 확보 후에만 교체한다. 링크 없이 PASS로 바꾸지 않는다.
